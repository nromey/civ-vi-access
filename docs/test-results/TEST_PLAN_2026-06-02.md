## 1. Verbosity pass (#4 core) — NEW, highest priority

The big behavior change. **Verbosity is now shared across the whole mod and
defaults to TERSE.** Toggle stays on **Alt+V** (it works; the earlier Alt+B
detour is reverted). Only known glitch: right after a notification fires, the
engine's bare-V Alert command can intercept Alt+V and speak "Alert" instead of
toggling — handled separately, not by moving the key.

Test:
- **Move the cursor over tiles in the world.** You should now hear a **brief**
  read: terrain + coords + any units/city on the tile. NOT the full datasheet
  (no movement cost / appeal / continent / yields wall). This is the fix for
  "it reads me lots of information as I move."
- **Press Alt+V.** Should say "Verbose on." Now move over tiles again → you
  should hear the **full** datasheet again (the old behavior). Alt+V again →
  "Verbose off" → back to brief.
- **Open a menu screen** (e.g., Esc options, or a setup screen if you start a
  new game) and press **Alt+V** there → it should toggle the same setting (the
  toggle now propagates across contexts — that was broken before).
- **Where-am-I coords:** press **S** (quick) and **Shift+S** (survey) on a
  world tile → both should now END with "X n, Y n". Alt+S still speaks coords
  only. Previously only Alt+S spoke numbers.

Risk flags / known-incomplete:
- **Post-notification Alt+V → "Alert"** still possible until the narrow
  collision fix lands; if you hear "Alert," press Alt+V again.
- **Pickers still force chatty.** CityState / Leader / MultiSelect / Scenario
  pickers still have `alwaysVerbose` and will ignore terse for now — I have NOT
  yet removed those overrides (the "respect it everywhere" change). So those
  screens stay chatty this build. Flag if that bugs you; it's the next #4 step.
- **The HexCursor selection read** (when you select a unit/tile) may still be
  verbose — I gated the PlotToolTip read (the loud one) but want to confirm
  live whether the selection read also needs gating.
- **NOT yet built**: the I-key consolidation (bare I = image desc always,
  Shift+I = pedia), and the early-game "press Ctrl+T / Shift+I" key reminders.
