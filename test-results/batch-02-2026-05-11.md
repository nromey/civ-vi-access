# Civ VI Access — Test Script

Manual test script for verifying accessibility flows. Run after every batch of changes.

Each step has three labeled fields: **Action**, **Expected**, **Result**. Fill in your result after the `****` marker (find-replace `****` to record outcomes). If any step fails, note what you actually heard / observed in the result field and don't proceed past it — the failure is the signal for what to fix next.

---

## Batch 02 — Menu sweep round 1 (LoadGameMenu, submenu verification, in-game probe)

Prereqs:
- Civ VI installed at default Steam path.
- `CivVIAccess.Launcher.exe` rebuilt and present at `civilization-vi-screenreader-access\CivVIAccess.Launcher\bin\Debug\net10.0\`.
- Tolk-compatible screen reader running (NVDA, JAWS, SAPI, etc.).
- Both Civ VI and any prior launcher instances closed (verify in Task Manager).
- `UserOptions.txt` already contains a valid `CopyrightAccept <version>` line (i.e. you've accepted the EULA at least once on this build). If you want to retest the first-launch flow, follow the EULA reset steps at the bottom.

## Diagnostics if anything fails

If the launcher narrates the long first-launch message but you've already accepted: the `CopyrightAccept` check in `Program.cs` is mis-evaluating. Send the `CopyrightAccept` line from your `UserOptions.txt`.

If submenu navigation is silent: open Lua.log at `%LOCALAPPDATA%\Firaxis Games\Sid Meier's Civilization VI\Logs\Lua.log` and search for `SCREENREADER` lines after the submenu Enter. If the lines are there but you didn't hear them, the watcher is stuck. If they're absent, `MainMenuAccess.NotifySubMenuBuilt` didn't fire — needs investigation.

If LoadGameMenu announcements don't fire on show: check Lua.log for `Load Game Menu.`. If absent, our companion didn't load (probably a modinfo issue). If present but not heard, the watcher is stuck.

If in-game is totally silent: the existing inline hooks aren't firing — could mean we need to write companion files for the in-game screens too. That's next session's work.

## Batch 01 — EULA reset recipe (if you want to re-test first-launch flow)

To reset EULA acceptance so the IntroScreen flow fires again, run in Git Bash:

    USER_OPTS="$LOCALAPPDATA/Firaxis Games/Sid Meier's Civilization VI/UserOptions.txt"
    cp "$USER_OPTS" "$USER_OPTS.civ6access-backup"
    sed -i '/^CopyrightAccept /d' "$USER_OPTS"

Then close any running launcher or Civ VI and relaunch. The launcher should narrate the long first-launch message and IntroScreen should announce the EULA. Press Enter or Space to accept.

To restore manually if needed: `mv "$USER_OPTS.civ6access-backup" "$USER_OPTS"`. Otherwise Civ VI rewrites the line during the next EULA accept automatically.
